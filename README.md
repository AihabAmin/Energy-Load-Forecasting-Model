# ⚡ Energy Load Forecasting Model

## 📌 Project Overview

This project is a Machine Learning based Energy Load Forecasting System that predicts future electricity demand using historical load data.

The system compares multiple ML regression models and provides forecasting results through a PyQt5 dashboard.

---

## 🚀 Features

- Energy Load Prediction
- Machine Learning Model Comparison
- Best Model Selection
- Forecast Generation
- MAPE and RMSE Evaluation
- PyQt5 Dispatch Dashboard
- Load Visualization

---

## 🤖 Machine Learning Models

The following models are compared:

- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor
- XGBoost Regressor


## 📊 Evaluation Metrics

Models are evaluated using:

- MAPE (Mean Absolute Percentage Error)
- RMSE (Root Mean Square Error)
